Q10. Word Problem
Tank filled = 3/4
Water used = 1/2 of 3/4 = 3/8

Q16. Classify each number
–12 → Integer, Rational.
Explanation: negative whole number; can be written as –12/1.
0 → Whole, Integer, Rational.
Explanation: 0 is a whole number (not a natural number here), an integer, and equals 0/1.
7 → Natural, Whole, Integer, Rational.
Explanation: positive counting number; fits every listed set except irrational.
3.75 → Rational.
Explanation: 3.75 = 375/100 = 15/4 (terminating decimal → rational).
√64 → Natural, Whole, Integer, Rational.
Explanation: √64 = 8, a positive integer.
√8 → Irrational.
Explanation: √8 = 2√2, and √2 is irrational, so √8 is irrational.
π → Irrational.
Explanation: classic irrational number (non-terminating, non-repeating decimal).

Q20. Challenge
“Every real number is either rational or irrational.” — Correct.
Justification: By definition the real numbers split into two disjoint groups: those that can be written as a fraction p/q (rational) and those that cannot (irrational). Example: 1/3 is rational; π is irrational. (Note: this statement concerns real numbers only — complex numbers have a different classification.)
