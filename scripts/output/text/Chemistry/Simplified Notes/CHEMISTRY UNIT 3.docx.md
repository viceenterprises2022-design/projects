Unit 3: The Periodic Table
1. History of the Periodic Table
Early Attempts to Organise Elements
Döbereiner’s Triads
German scientist Johann Döbereiner grouped elements into sets of three called triads.
Elements in each triad had similar properties.
Example:
Important Idea
The middle element’s atomic mass was roughly the average of the other two.
Example:
(Lithium = 7, Potassium = 39, Sodium = 23)
Limitation
Only a few elements fit into triads.
Newlands’ Law of Octaves
John Newlands arranged elements by increasing atomic mass.
He noticed that every 8th element had similar properties.
Example:
Like musical octaves:
Lithium and Sodium
Fluorine and Chlorine
Limitation
Worked only for lighter elements.
Failed for heavier elements.
Mendeleev’s Contribution
Dmitri Mendeleev
Arranged elements by atomic mass.
Placed elements with similar properties in the same columns.
Major Achievements
Left gaps for undiscovered elements.
Predicted properties of missing elements accurately.
Importance
His predictions helped scientists discover new elements later.
Modern Periodic Table
Problem with Mendeleev’s Table
Some elements did not fit correctly using atomic mass.
Henry Moseley’s Discovery
Elements should be arranged by atomic number instead of atomic mass.
Atomic Number
Number of protons in the nucleus.
Modern Periodic Table
Elements are arranged in increasing atomic number.
2. Arrangement of Elements
Arrangement Based on Atomic Number
Elements are ordered from smallest atomic number to largest.

Electronic Arrangement

Groups and Periods
Groups
Vertical columns in the periodic table.
Elements in the same group have:
Same number of valence electrons
Similar chemical properties
Example:
Group I:
Lithium
Sodium
Potassium
All have 1 valence electron.
Periods
Horizontal rows in the periodic table.
Period number = number of occupied electron shells.
Example:
3. Electronic Arrangement (Up to Calcium)
Rules
First shell holds 2 electrons.
Second shell holds 8 electrons.
Third shell holds 8 electrons (for first 20 elements).
Electronic Arrangements
Valence Electrons
Electrons in the outermost shell.
Determine chemical properties and reactivity.
Example:
Sodium = 2,8,1 → 1 valence electron
Chlorine = 2,8,7 → 7 valence electrons
Relation Between Group Number and Valence Electrons
4. Group I – Alkali Metals
Group I Elements
Lithium (Li)
Sodium (Na)
Potassium (K)
Rubidium (Rb)
Caesium (Cs)
Physical Properties
Alkali metals are:
Soft
Shiny when freshly cut
Low density
Good conductors of heat and electricity
Have low melting points
Chemical Properties
They:
React vigorously with water
Form alkaline solutions
Produce hydrogen gas
Example Reaction:
Trend Down the Group
Reactivity increases down the group.
Reason
Outer electron is further from the nucleus.
Easier to lose the electron.

Group VII Elements
Fluorine (F)
Chlorine (Cl)
Bromine (Br)
Iodine (I)
Physical Properties
Chemical Properties
Non-metals
Exist as diatomic molecules:
Cl₂
Br₂
I₂
Form salts when reacting with metals.
Example:
Trend Down the Group
Reactivity decreases down the group.
Reason
Harder to gain electrons as atomic size increases.
