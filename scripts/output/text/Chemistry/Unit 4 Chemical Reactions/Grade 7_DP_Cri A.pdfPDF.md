Grade 7
Drill and Practice
Unit 4: Chemical Reactions
Criterion A
1.  Distinguish between a cation and an anion using an example.
2.  Define a polyatomic ion and give one example.
3.  Identify the formula and charge for the following ions:
a) Sodium
b) Nitrate
c) Carbonate
4.  Write the chemical formula for the following compounds:
a) Calcium chloride
b) Ammonium sulfate
c) Magnesium nitrate
5.  Name the following chemical formulas:
a) NaCl
b) CuSO₄
c) CO₂
6.  Describe the following types of reactions:
a) Synthesis
b) Decomposition
c) Single displacement
7.  Identify the type of reaction and construct a balanced equation for the following:
a) Zinc + Hydrochloric acid → Zinc chloride + Hydrogen
b) Water → Hydrogen + Oxygen
8.  Balance the following chemical equation:
Fe + O₂ → Fe₂O₃
