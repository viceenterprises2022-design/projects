|---|---|---|

| `fetch_substack` | `substack_to_slack.py` | RSS → full article → Slack |
| `fetch_arxiv` | `arxiv_to_notebooklm.py` | Paper → NotebookLM → Slack |
| `manage_channels` | `youtube_to_notebooklm.py` | `--add-channel`, `--remove-channel` |
