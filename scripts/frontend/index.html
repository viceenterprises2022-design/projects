Frequently Asked Questions

Have questions about the AlphaEdge system, databases, or daemon services? We have answers.

How is the 10-Factor Signal calculated?

+
The signal engine evaluates 10 separate market factors: Trend direction, Dow Jones futures, India VIX values, options chain Open Interest skew, VWAP crossovers, SuperTrend indicators, RSI levels, the US Dollar Index (DXY), Crude Oil pricing, and the Put-Call Ratio (PCR). Each factor receives a score of -1 (bearish), 0 (neutral), or +1 (bullish). Summing these outputs produces the composite score. A score ≥ 6 triggers a BUY signal, ≤ 4 triggers a SELL, and anything else results in a NEUTRAL stance.

What data sources are utilized by AlphaEdge?

+
AlphaEdge queries the Upstox Developer REST API using secure JWT bearer tokens for Indian indices (Nifty, Sensex, BankNifty) and live option chain structures. Macro data including the US30, Crude Oil, DXY, Gold, Silver, and VIX are fetched from Yahoo Finance. Altcoin perps and depth matrices are connected to Deribit and Binance via websockets.

How do I manage and check the background daemons?

+
The collectors run under systemd user mode services. You can use standard commands like `systemctl --user status alphaedge-collector` or check all services by running the unified helper script `bash check_daemons.sh` from the repository root. Logs can be inspected via journalctl using `journalctl --user -u alphaedge-collector.service -f`.

Is this platform open source and self-hostable?

+
Yes! AlphaEdge is written entirely in Python, vanilla HTML/CSS/JS, and SQLite. You can host the entire system on a local Linux VPS or single board computer. All dependencies are managed cleanly through standard python virtual environments (`venv`) and bun modules.
