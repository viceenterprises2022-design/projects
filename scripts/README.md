# Scripts Repository

Comprehensive collection of scripts for Market Intelligence, AI Search, and automated reporting.

## Quickstart

```bash
# project bootstrap commands — fill in from docs/architecture.md
```

## Docs

| File | What's in it |
|---|---|
| [`AGENTS.md`](AGENTS.md) | Universal agent context (stack, commands, conventions). |
| [`docs/index.md`](docs/index.md) | Index of every subsystem with one-line descriptions. |
| [`docs/architecture.md`](docs/architecture.md) | Architecture, setup, design notes. |
| [`docs/runbook.md`](docs/runbook.md) | Operations: systemd, cron, troubleshooting, recovery. |
| [`docs/projects/`](docs/projects/) | One file per subsystem. |
| [`CHANGELOG.md`](CHANGELOG.md) | Dated history of changes (formerly Session Memory). |

## Use the cross-agent context router

```bash
start scripts repository              # full bundle
start scripts repository --short      # AGENTS.md only
```
